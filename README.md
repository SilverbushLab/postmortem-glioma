# postmortem-glioma

Most of the code is written in R (version 4.5.1) and provided in the form of R markdown (.RMD) files.  

Python (version 3.9) is used for the tensor decomposition (see **Tensor Decomposition** folder) and the tensor-decomposition-based cell type classifier (see **Classifier** folder).  

The code in the **Pre-processing** should be run first. It pre-processing the Seurat objects.  

## Pre-processing
**nomura_2025_GBM_preprocessing.RMD**: Data pre-processing for the Nomura 2025 GBM snRNA-seq dataset.   
**my_data_preprocessing.Rmd**: Data pre-processing for the postmortem glioma snRNA-seq data generated by this study. Starts from the 10X Cell Ranger output and creates a Seurat object.      
**healthy_references_preprocessing.RMD**: Data pre-processing for the Velmeshev 2019 snRNA-seq dataset.     
**sussman_2024_pHGG_preprocessing.RMD**: Data pre-processing for the Sussman 2026 snRNA-seq dataset.  
**macnair_2024_MS_preprocessing.RMD**: Data pre-processing for the Macnair 2024 Multiple Sclerosis snRNA-seq dataset.  
**wang_2022_GBM_preprocessing.RMD**: Data pre-processing for the Wang 2022 GBM snRNA-seq dataset.    


## Classifier
Code for the tensor-decomposition-based cell type classifier. The code works for the Herring 2022 dataset (demonstrated in the paper) and it also works for the Sussman 2026 pHGG dataset and the data generated in this study.     
**1_3_format_input_output_cell_type_classifier.Rmd**: This code is run before and after the classifier. It is run before the classifier to format the dataset so that it is ready for the classifier. It is run after the classifier to generate a UMAP with the classifier predictions (Fig. 2H).     
**2_cell_type_classifier_using_tensor_signatures.ipynb**: Python code for the classifier. It also generates the confusion matrix as in Fig. 2G and Supp Fig. 2I.

## Tensor Decomposition
The code here should be run in order:  
**1_sussman2024pHGG_prepare_input_for_tensor_decomp.RMD**: R code to format Sussman 2026 pHGG data for input into the tensor decomposition pipeline. Starts from the Seurat object and outputs gene by cell type .tsv files for each sample that are used to make the tensor.     
**2_sussman2024pHGG_run_tensor_decomposition.ipynb**: Python code to run the 3D non-negative PARAFAC tensor decomposition, implemented in tensorly, multiple times using different seeds.    
**3_sussman2024pHGG_consensus_factors.ipynb**: Python code to obtain consensus factors using the tensor decomposition output from **2_sussman2024pHGG_run_tensor_decomposition.ipynb**. The consensus factors method is based on Chafamo, Shanmugam, & Tokcan 2024 (DOI: 10.1186/s12859-024-05886-4).
